KidBucks Support

Getting Started

  • Create a family: Open KidBucks and tap "Create a Family" to get started.
  • Add children: Go to Settings and tap "+ Add Child" to add your kids.
  • Add transactions: Tap "+ Add Transaction" on the home screen to record deposits and withdrawals.

Family Sharing

  • Invite a parent: The family owner can share their invite code (found in Settings) so a second parent can join.
  • Join a family: Use the invite code from the other parent to join and sync data.
  • Sync: Both parents see the same balances and transactions in real time.

Troubleshooting

  • Data not syncing? Make sure both devices are connected to the internet. Pull down on the home screen to force a sync.
  • Can't add a second child? Free accounts support one child. Upgrade to Family Sharing for unlimited children.
  • Lost data after reinstall? If you previously created a family, tap "Join with an Invite Code" and enter your family's code to restore access.
